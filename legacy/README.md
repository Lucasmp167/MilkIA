# Cópia de segurança do original

`milkiq-original-etapa1-2026-11-11.html` é a cópia **byte a byte** do artifact "MilkIQ · Leite IA" no claude.ai (build `etapa1-2026-11-11`, dados v2), conferida contra o artifact em 11/11/2026.

- **Não edite este arquivo.** O hash SHA-256 está em `SHA256SUMS`, e os testes (`npm test`) falham se o arquivo for alterado.
- No git, a mesma versão está marcada com a tag `v-original`.
- Para usar a cópia, basta abrir o arquivo no navegador. Ela lê e grava os mesmos dados (`localStorage`) e o mesmo formato de backup que o `index.html` atual.
